## Reply behavior and verification

Coverage includes YES delivering the promised artifact; STOP persisting across conversations; price, no-time and already-done objections; four repeated auto-replies without a human session; planning intent handoff; consent and fresh IDs/event terms. Existing context-update, reply-retry, template rendering and five-route tests remain in place.

The oversized-upload test now sends the oversized Content-Length without an unnecessary body, avoiding an intermittent Windows TCP reset on early server rejection. The API implementation and 413 response are unchanged.

Local verifier: PASS, 363 requests, maximum 24.23 ms; results/composer-local-verification.json. A new local server ran the edited code. Existing local/public deployment reports were left unchanged.

## Limits

No official LLM judge was run; no quality score or measured merchant-response uplift is claimed. No deployment or push performed. The existing public pass applies to the previously deployed version.

Messages still use fixed rule families and partly English evidence in regional code-mix. Some drafts remain cautious or long; a judge may prefer shorter copy. Scarcity, peer social proof, medical outcomes, inventory, new prices and execution claims are not invented. Supplied research/compliance material is attributed, not independently validated. Missing facts still suppress; this is deliberate. The bot has no booking, publishing, payment or registration integration.
